# Sododo Tribute – React + Vite

This project is a tribute site honoring **Alhaji Sheikh J.B. Sododo**, built with **React** and powered by **Vite** for fast development and deployment. It is hosted live on [Vercel](https://sododo.vercel.app).

## ✨ Features
- Responsive design with Tailwind CSS
- Dynamic sections: Hero, Biography, Leadership, Letter, Dua, and Gallery
- Smooth scroll and fade‑in animations on scroll
- SEO meta tags with `react-helmet-async`
- Modern card and box layouts for images and content
- Automatically updating footer year

## 🛠 Tech Stack
- **React** (UI framework)
- **Vite** (bundler & dev server)
- **Tailwind CSS** (styling)
- **react-helmet-async** (SEO meta management)
- **AOS** (scroll animations)
